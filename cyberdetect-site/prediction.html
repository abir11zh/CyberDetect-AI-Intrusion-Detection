How It Works

The Models Behind the Prediction

Each inference runs through both models; the ensemble picks the highest-confidence class.

XGBoost Classifier

Trained on 80 hand-crafted features (flow duration, packet length stats, IAT mean/std, flag counts…). Extremely fast inference (<1 ms per flow). Handles class imbalance via scale_pos_weight tuning.

LSTM Neural Network

Processes sliding windows of 20 consecutive packets to capture temporal dependencies. Two-layer stacked LSTM with attention mechanism. Best suited for slow-scan and low-and-slow attack detection.
